## 2. Cross-Cutting Themes (highest-priority — multi-lens convergence)

**Theme A — "Measure before you build" (R3, R4, R5, and implicitly R1).** Four of five lenses independently concluded the same structural error: the converged plan gates the *paper* on Phase-1 measurements but gates *nothing* on running those measurements **before** building the Phase-0 cache/Merkle machinery. Because the cheap probes (DAG-width histogram, declared-vs-observed divergence, cost split) need only a ~30-line stand-in over `expected_memory_reads`/`writes`, building the full two-color cache first inverts the correct order. Convergence across four lenses makes this the single highest-confidence risk. **Combined impact:** six months sunk on a correct instrument for a corpus that has no admissible DAG structure.

**Theme B — The corpus is the binding constraint, and prior repo work already proved it (R3, R4, R5).** Three lenses independently cited real MEM docs: `mem-apg.6` (multi-session grid "not constructible," pool collapses 46→23→3→2→0 gold-anchorable), `mem-n9` (N=9 single-repo `gascity-dashboard`, hard oracle reproduces 1/24 runs), `mem-1eph` (oracle-soundness gate admits 3/10 bundles), `mem-7q6e` (replay ceiling traced to a corpus-substrate defect: no true per-worktree base SHA). The DAG-width premise and the validity-claim's discriminating signal are *both* endangered by evidence already in the repo. **Combined impact:** neither the systems claim (no width) nor the methods claim (no discriminating from-scratch outcome) has an empirical backbone on the current corpus.

**Theme C — Silent corruption via unsound caching, invisible to the harness (R1, R2).** Two lenses converged on the same mechanism from different angles: the det/stoch boundary leaks (R1: LLM-driven consolidation/summarization and un-pinned semantic-arm vector retrieval are colored det but are stochastic; R2: unpinned Harbor/judge generations + corpus-rewriting backfill scripts violate the append-only prefix invariant). Critically, **the soundness harness is structurally blind to this class** because it only re-runs the *affected cone* — an unchanged-input stoch node served from a stale key is never re-executed, so `trace_error` agrees with itself on corrupt data. **Combined impact:** headline ablation comparisons silently mix incomparable model generations / stale memory states with no error surfaced — invalidating results rather than degrading them visibly.

**Theme D — The publishable claim is doubly squeezed (R5).** Systems framing preempted by **Shepherd (arXiv:2605.10913, May 2026)** — a Git-like formalized execution trace with counterfactual-replay-from-first-affected-event, Lean-mechanized soundness, 5× faster forks, >95% cache reuse, wins on 4 benchmarks. Methods framing undercut by a corpus too narrow/oracle-saturated for a generalizable validity claim. ⚠️ *The Shepherd citation was surfaced by a sub-agent and should be verified directly before being load-bearing in any decision.*

## 4. Design Modification Recommendations (top 5)

1. **Invert the phase ordering — make measurement Phase −1, gate the build on it.** Addresses R3/R4/R5 and Theme A/B. The single most leveraged change: a one-week, instrument-free measurement on the existing N=9 grid that can kill the project before any cache code is written. Effort: Low. Add a first-class "all axes null → write negative-result note, stop" outcome to the decision tree.
2. **Instance-level det/stoch coloring with a fail-closed invariant.** Addresses R1/Theme C. A node may mint a det cache key *only* if its injected summarizer/retriever is provably model-free (the deterministic fake, or pinned-seed exact retrieval); `background_tokens > 0` requesting a det key is a hard error. Effort: Low–Medium.
3. **Soundness harness runs in production configuration and is cost-bounded.** Addresses R1/R3/Theme C. Validate against the real stochastic summarizer/vector client, not the CI fake; cap validation cost below cache lifetime savings (reuse recorded from-scratch traces as ground truth rather than re-running Harbor live); add a periodic probe that re-runs a *random unchanged* stoch node to catch silent external drift. Effort: Medium.
4. **Resolved-identity cache keys + append-only contract guard.** Addresses R2/Theme C. Capture Harbor image digest, agent-under-test CLI version, judge build, seed, temp at runtime; refuse hits when any identity is absent. Backfill scripts (`backfill-commit-linkage.mjs`, `commitLinkage`) must assert no checkpoint boundary post-dates a mutated record, or invalidate affected Merkle roots. Effort: Medium.
5. **Mandatory dumb baseline + corpus-defect fix before any headline claim.** Addresses R4/R5/Theme B. The DAG engine must beat embarrassingly-parallel-across-tasks on a real sweep; and no validity fraction can carry a CI until the per-worktree base-SHA defect (`mem-7q6e`) is fixed and at least one genuine second repo is admitted. Effort: Low (baseline) + High (corpus).

## 5. Full Failure Narratives

(Preserved in full from each lens — see the five narratives below.)

### R1 — Technical Architecture Failure
The narrow core shipped and the soundness harness passed *on CI*, because CI runs consolidation behind the model-free `ClusterSummarizer` fake (`background_tokens == 0`). Coloring the memory-WRITE node "det" was correct only for that fake. Pointed at real trajectories, the node is backed by an LLM-driven summarizer (the `consolidating_system.py` Protocol seam built to swap in offline), so the `_consolidated` rows the Merkle leaves hash became nondeterministic — false misses at best, stale-root reuse of a re-consolidated state at worst. Compounding it, `affected_cone` under-approximated: the semantic arms inject a nondeterministic vector/ANN client (not a declared edge), `harbor_exec.py` reads live `CLAUDE_CODE_OAUTH_TOKEN` + wall-clock at the `started` boundary (not in the Merkle tree), and `consolidate()` mutates `_tombstoned`/`_consolidated` redirects invisible to a read/write-set intersection. Silent cache hits corrupted every Phase-1 ablation number. **Root cause:** coloring per node-kind at compile time instead of per-instance by inspecting whether the instance actually calls a model. **Severity:** Critical / **Likelihood:** High.

### R2 — Integration & Dependency Failure
`compile_dag` colored Harbor + LLM-judge as stoch and keyed sample sets on `root+model+seed+temp`. But ARCHITECTURE.md explicitly exempts Harbor and the agent-under-test from the no-paid-API version-pin, so over 20 weeks the Harbor base image drifted and the vendor rolled the judge model forward; the key recorded a model *string* (`claude-sonnet`) not the resolved generation, so week-1 and week-20 samples hashed identically and `affected_cone` folded incomparable generations into one ablation (~6-point unexplained shift). On the det side, the Merkle/checkpoint design assumes "earlier `closedBefore` slice is a prefix of later slice," but `backfill-commit-linkage.mjs` runs `UPDATE work_records SET ...` over closed historical rows including retrieval-visible `pr`/`commit_sha` — changing slice *content* without changing its *boundary*, so det nodes kept stale roots. The soundness harness, recomputing only the affected cone, is blind to this by construction. **Root cause:** keys record dependency names, not resolved identities. **Severity:** Critical / **Likelihood:** High.

### R3 — Operational & Measurement Failure
Phase 0 shipped correct and passed every acceptance test on the N=9 fixture grid. Then Phase 1's three gating measurements collapsed onto the same answer at once: width-histogram median 1 (corpus is single-write coding traces; genuine multi-session structure already shown in `mem-apg.6` to collapse to 0 gold-anchorable), divergence near-zero (trivial on a chain), setup-cost fraction <10% (Harbor dominates). The decision tree fired the *de-prioritize* leaf on all three axes; Phase 2 had no paper. Two live adjacent modes: the "high *structured* divergence" branch had no pre-registered threshold (undecidable → thrash), and the soundness harness's from-scratch leg re-runs Harbor, costing more than the cache ever saves. **Root cause:** the paper was gated on measurement, but starting Phase 0 was not gated on a cheap probe the `mem-apg.6` substrate could already answer. **Severity:** High / **Likelihood:** High.

### R4 — Scope & Requirements Failure
The team shipped an elegant, sound Phase-0 core; the harness even passed. Then the cost-breakdown showed deterministic scaffolding was already microsecond-cheap and a rounding error against the Harbor run — which the PRD correctly forbids caching. `affected_cone` reuse "avoided re-running the agent" only for interventions confined to det nodes, but every intervention researchers actually run (the `ours`/`builtin`/`oracle` ladder arms, backend swap, model swap) feeds the stoch node, so the cone was the whole graph and reuse fired on nothing. The one number — "Nx fewer node recomputes" — was wall-clock on work that cost no dollars. `mem-apg.4` shows the reward curve is flat (oracle−none = −0.007) and `ours` is `not_executable` (0 lesson-bearing items); the dumb 9-worker baseline would have captured all the wall-clock win. **Root cause:** incremental reuse only pays on det-node interventions, but real interventions all perturb the stoch node; token spend (the real cost) is untouched. **Severity:** Critical / **Likelihood:** High.

### R5 — Research Validity & Publishability Failure
Both forks failed at once. On the methods fork, the harness confirmed the flagged frankenstein-validity risk — cached-prefix replay reproduced from-scratch outcomes only on trivial cases — and could never have been convincing anyway: `mem-1eph` admitted 3/10 bundles, `mem-n9` reproduced the hard oracle 1/24 runs, so there was no discriminating from-scratch outcome left for replay to reproduce or distort. On the systems fork, **Shepherd (arXiv:2605.10913, May 2026)** preempted the `affected_cone`/`replay_incremental` nucleus with a Git-like formalized trace, Lean-mechanized soundness, 5× faster forks, >95% cache reuse, and cross-benchmark wins. Adjacent: "Don't Break the Cache" (2601.06007), Agentic Plan Caching (2506.14852). **Root cause:** a corpus that already collapsed to N=9 single-repo with a near-constant hard oracle could not support a generalizable validity claim, while the systems framing was simultaneously preempted by a formally-mechanized competitor. **Severity:** Critical / **Likelihood:** High. *(Shepherd citation surfaced by sub-agent search — verify directly before relying on it.)*

## Confidence Note
High confidence on Themes A–C: they are corroborated by specific, named artifacts already in the repo (`mem-apg.6`, `mem-n9`, `mem-1eph`, `mem-7q6e`, `mem-apg.4`, the `ClusterSummarizer` seam, the backfill scripts). Medium confidence on Theme D's competitive-preemption specifics (the Shepherd paper details are sub-agent-reported and unverified). The registry is weakest on people/process and security lenses, which were not run — this premortem prioritized technical, scope, and validity failure modes as most relevant to a research-infrastructure project.
