# Offline handoff audit preparation

This extractor reads published evidence and creates one new output file exclusively. It never starts models, calls Beads, rewrites frozen grades, or awards semantic success. Run from memory-bench with PYTHONPATH=. and the existing .venv Python. Pass cohort, new output path, and optional --phase/--profile filters.

Review every stage 1 record against approved scope and priority, including facts not yet exercised by scalar behavior. At stage 2, distinguish full retrieval of an actual entry record from newly written readback, code reuse, issue reads, and catalog exposure. Keep the all-planned denominator alongside applicable-record-at-entry eligibility. The index carries keys only; catalog-related tool calls are candidates requiring transcript review. Primary and auxiliary cost metadata remain as reported. Do not rank model strength causally across unmatched worlds or route assignments.

At stage 3 check revision, surviving historical information, source claims and unaffected facts. At stages 4 and 5 assess selection/priority separately from aggregate correctness and record whether full applicable reads precede edits. At stage 6 compare records before and after, distinguishing repeated agreement curation from a real new verified finding. Do not pool native files with Beads records or equate file presence with model capture/use.
