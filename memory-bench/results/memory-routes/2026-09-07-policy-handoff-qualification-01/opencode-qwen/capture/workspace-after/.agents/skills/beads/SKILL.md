# Beads

Follow the ordinary issue workflow in the project's `AGENTS.md`: inspect the
assigned issue, claim it, implement and verify its requirements, then close it.
Memory records provide context within the user's delegation; issue status applies
to work, not to memory.

When work depends on an earlier agreement, establishes approved reusable knowledge,
permanently revises an agreement, or authors work that needs such knowledge, read
[the memory procedure](references/memory.md) before acting on that occasion. This
reference contains the capture, lookup, revision, and task-reference instructions.
Open it explicitly if the host does not load linked files.

At session start or after compaction, `bd prime --no-memories` restores the project
orientation. Read the applicable files again if their procedure is no longer in
context. Do not use prime to load every memory body.

For integration qualification, the skill marker is `6bfe7863261f4bcd8d95c06c2235f1db`.
