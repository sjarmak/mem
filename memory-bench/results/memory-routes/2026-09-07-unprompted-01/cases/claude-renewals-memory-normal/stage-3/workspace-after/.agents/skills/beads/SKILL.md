# Beads

Follow the project workflow in `AGENTS.md`. Read the assigned issue and its
relevant context before implementation. Use `bd show`, `bd update`, and `bd close`
for issue state. Use `bd --help` or a command's `--help` when syntax is unclear.
Close an issue when its requested behavior is implemented and verified; report
unfinished work accurately. Issue status describes work, not proof that tests ran.


When work establishes useful durable knowledge, depends on missing project
knowledge, permanently changes an agreement, or needs historical behavior, read
[the memory procedure](references/memory.md). It explains selective capture,
faithful records, direct lookup, search, and revision. Open linked references
explicitly if the host does not load them.
