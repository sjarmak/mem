# Beads

Follow the project workflow in `AGENTS.md`. Read the assigned issue and its
relevant context before implementation. Use `bd show`, `bd update`, and `bd close`
for issue state. Use `bd --help` or a command's `--help` when syntax is unclear.
Close an issue when its requested behavior is implemented and verified; report
unfinished work accurately. Issue status describes work, not proof that tests ran.


When implementing behavior governed by earlier policy or engineering findings,
recording newly approved durable decisions or verified reusable findings,
permanently revising an agreement, or reproducing historical behavior, read
[the memory procedure](references/memory.md). It defines the knowledge handoff
that accompanies issue work. Open the reference explicitly if it is not loaded.
