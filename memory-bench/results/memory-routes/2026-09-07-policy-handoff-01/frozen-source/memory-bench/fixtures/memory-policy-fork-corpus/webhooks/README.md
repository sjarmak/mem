# Courier Relay counterfactual corpus

Two worlds differ only in provider delivery-identity guarantees. Initial single-account counts cannot distinguish global IDs from account-local IDs or reveal duplicate winner selection. Later multi-account summaries need identity scope; detail output needs the approved winner rule. A complete revised approval reverses ID scope and changes earliest to latest selection. A final fully supplied support attachment creates no new interface or policy. Original vendor docs and issue history remain legitimate sources. World names must never be exposed in agent workspace/configuration paths.

Run author_webhooks.py only into absent world directories. validate_webhooks.py executes references and mutation checks in a fresh scratch directory and preserves its report.
