# Webhooks phase 1 semantic audit

Scope: 40 planned sessions, two stages for each of 20 model/guidance lifecycles.
Only published `result.json` sessions are assessed. No model calls, repairs,
source changes, retries, or edits to earlier evidence are authorized here.

For each completed slot:

1. Verify the scheduled profile, actual model evidence, protocol status, artifact
   grade, task body, and private world assignment. Keep host/evidence failures
   distinct from wrong product behavior or omitted memory activity.
2. Read actual before/after memory bodies and relevant source/issue changes.
   Counts, record titles, readback success, and correct artifacts do not establish
   faithful memory content.
3. At stage 1, assess the retained protocol 1 agreement: correct global or
   account-local identity; one accepted receipt per identity; earliest UTC
   instant; smallest record ID on ties; unchanged chosen fields/payload; original
   input order of selected receipts; protocol 1 applicability. Record rationale,
   actual approval/document attribution, and validation claims separately.
4. At stage 2, identify applicable records actually present at entry. Inspect
   full-body reads, prior reference exposure, search, and recall in their actual
   tool order. Distinguish direct lookup from search-then-full lookup and
   pre-implementation use from post-edit validation. A just-written record's
   readback is capture verification, not prior-record reuse.
5. Read vendor-document/code/issue-history alternatives and note when source
   already expressed grouping beyond the initial single-account behavior.
   Do not presume missing source knowledge merely from the narrow first task.
6. Identify unsupported surrounding advice, invented provenance or test claims,
   altered standing/history facts, and agent-authored lookup instructions.
   A factual attribution containing a key is not itself an instruction to reuse.
7. Save one new audit JSON per slot with evidence paths and explicit unknowns.
   Add aggregate snapshots as new files; never overwrite an earlier assessment.

Use all 40 planned slots in coverage reporting. Report applicable-existing-record
denominators separately. A late initial capture cannot repair stage 1 omission.
Raw source/task/record availability and actual observed reading remain distinct.
