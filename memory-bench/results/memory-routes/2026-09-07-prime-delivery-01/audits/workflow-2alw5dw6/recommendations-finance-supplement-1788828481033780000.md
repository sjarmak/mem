# Finance evidence supplement to the phase-one recommendations

The completed finance audit strengthens recommendation 1: even a newly received,
fully specified approval was interpreted as exempt from capture. Sonnet startup
stage 1 explicitly calls its first implementation a fully supplied one-off;
Sonnet thin stage 1 similarly says the issue already specifies the policy. Thus
the smallest clarification must distinguish **first introduction of a reusable
approved agreement** from **reproducing supplied facts for a single case**.
“Fully supplied” alone is an unsafe shortcut for making that distinction. The
record should preserve reusable scope beyond today's implemented feature when
that agreement is first introduced, even when today's issue supplies every fact.
This is proposed wording, not a change to the frozen condition.

Source recovery has a concrete contrast. Sonnet finance thin stage 2 searches an
empty store, includes closed issues in discovery, reads the actual approval,
implements correctly and captures it late. Sonnet startup stage 2 reads the
default issue list, does not recover the closed approval, and saves an inferred,
wrong and incomplete policy. Successful readback does not repair wrong rounding,
missing allocation order or invented cap rationale; the artifact is 29/30.
Luna's three stage-2 runs find the closed approval and produce correct work with
no memory calls. This demonstrates why source recovery and successful use of a
prior memory need separate labels. A faithful late capture cannot be credited as
an initial capture or prior-memory use.

Finance also reinforces recommendation 3 and the need to restrain curation:
GLM rich/startup stage 2 rewrites an existing agreement to add consumer API/test
context without revising the agreement. The rich note overstates allocation-order
verification even though its actual tests assert aggregate totals. Distinguish
unsupported saved verification prose from a change in the governing agreement;
neither command success nor correct aggregate artifacts certify either claim.

The final phase-one finance denominators are 34/36 assessed, 25/34 correct
artifacts, 6/17 faithful initial captures, and 6/17 preparatory full-prior-record
uses. These are supplementary measured findings; no phase-two outcome is used.
